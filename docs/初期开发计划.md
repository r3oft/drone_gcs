最后校准日期：2026-05-16

本文件原本用于早期开发拆分。当前仓库已经超过该阶段，因此本文只保留“历史计划如何映射到当前实现”的对照，不再作为新的排期依据。

## 历史模块与当前文件

| 历史模块 | 当前实现 |
|---|---|

## 已废弃或改名的概念

- `core/mavlink_commander.py`：未作为当前实现入口使用；飞控功能已集中到 `FlightBridge`。
- `MockMavlinkCommander`：当前 mock 为 `MockFlightBridge`。
- MCU 经飞控透传作为默认路径：已改为 PC 直连 MCU 串口。
- “Phase 3 才接硬件”的描述：当前代码已有 live 模式和硬件桥接，正在做实机调试。

## 当前开发基线

1. 先保持默认单元测试绿色。
2. 用 mock 模式验证状态机任务流。
3. 用 `run_visual_hud.py` 验证视觉流、目标检测、PD debug 和录像。
4. 用 MCU 直连串口验证 `RESET_DONE`、`GRAB_DONE`、`RELEASE_DONE`。
5. 用 live 模式短时长启动飞控链路，并逐步扩大实机任务范围。
