### 在windows终端共享串口
```powershell
# PowerShell 通过管理员打开

# 查看端口
usbipd list 

# 绑定设备（只需第一次，永久生效）
usbipd bind --busid 2-1

# attach 串口，注意关闭windows系统中对该串口的占用
usbipd attach --wsl --busid 2-1

# detach 串口，windows系统使用串口时需要detach
usbipd attach --wsl 2-1
```

### 在wsl(linux)端查看串口
```bash
# bash
ls /dev/tty* # USB设备一般默认前缀tty
```
在wsl中连接飞控时使用看到的数传对应的tty*串口(例如ttyUSB0)
