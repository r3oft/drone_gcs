# 飞控与 MCU 通信配置

最后校准日期：2026-05-16

当前版本将“飞控链路”和“MCU 末端执行器链路”解耦：

- Pixhawk 只负责飞行控制和遥测。
- MCU 默认由 PC 通过独立串口直连。
- 旧的 Pixhawk `SERIAL_CONTROL` 透传路径仍保留为兼容选项。

## Pixhawk MAVLink

配置位置：`config/default.yaml`

```yaml
mavlink:
  connection: "udp:192.168.4.1:14550"
  baud: 57600
  heartbeat_timeout_s: 5
  reconnect_enabled: true
  reconnect_max_attempts: 3
  reconnect_backoff_s: 1.0
```

相关 CLI：

```bash
--conn udp:192.168.4.1:14550
--baud 57600
--heartbeat-timeout 5
```

`FlightBridge` 使用 DroneKit/PyMAVLink 建立连接，负责：

- `connect()`
- `arm_and_takeoff()`
- `send_body_velocity()`
- `land()`
- `set_mode()`
- `get_telemetry()`

## MCU 直连串口（默认）

配置位置：

```yaml
mcu:
  transport: "direct_serial"
  port: "/dev/ttyACM0"
  baudrate: 115200
  read_timeout_s: 0.02
  write_timeout_s: 0.5
  grab_timeout_s: 10
  release_timeout_s: 10
  retry_max: 2
```

相关 CLI：

```bash
--mcu-transport direct_serial
--mcu-port /dev/ttyACM0
--mcu-baud 115200
```

协议为 ASCII 文本行：

| 方向 | 内容 |
|---|---|
| PC -> MCU | `RESET\n` |
| PC -> MCU | `START_GRAB\n` |
| PC -> MCU | `START_RELEASE\n` |
| MCU -> PC | `RESET_DONE\n` |
| MCU -> PC | `GRAB_DONE\n` / `GRAB_FAIL\n` |
| MCU -> PC | `RELEASE_DONE\n` / `RELEASE_FAIL\n` |

实现文件：`core/mcu_bridge.py::DirectSerialMCUBridge`

## Legacy Pixhawk SERIAL_CONTROL

如必须通过 Pixhawk UART 透传 MCU，可切换：

```yaml
mcu:
  transport: "pixhawk_serial_control"
  pixhawk_serial_port: 4
  baudrate: 115200
```

CLI：

```bash
--mcu-transport pixhawk_serial_control
```

该路径由 `core.flight_bridge.MCUBridge` 实现，仅作为兼容与回退方案；当前调试优先使用 PC 直连 MCU 串口，以减少飞控与末端执行器之间的耦合。

## 常用命令

mock 验证：

```bash
python main.py --mode mock --start --mock-fast --duration 2 --no-flight-recorder
```

live 启动保护：

```bash
python main.py \
  --mode live \
  --start \
  --confirm-live-start \
  --conn udp:192.168.4.1:14550 \
  --mcu-port /dev/ttyACM0
```

默认单元测试：

```bash
python -m pytest -q
```
