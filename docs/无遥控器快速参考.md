# 无遥控器快速参考

最后校准日期：2026-05-16

## 结论

优先使用遥控器。若必须无遥控器，先完成软件、视觉、MCU、飞控链路的逐级验证，并准备物理断电方案。

## 必跑检查

```bash
python -m pytest -q
python main.py --mode mock --start --mock-fast --duration 2 --no-flight-recorder
python scripts/run_visual_hud.py --duration 20 --draw-targets all --debug-targets selected
```

## live 启动保护

live 自动开始任务必须带：

```bash
--mode live --start --confirm-live-start
```

示例：

```bash
python main.py \
  --mode live \
  --start \
  --confirm-live-start \
  --duration 3 \
  --conn udp:192.168.4.1:14550 \
  --mcu-port /dev/ttyACM0
```

## 当前 MCU 链路

默认是 PC 直连 MCU 串口：

```yaml
mcu:
  transport: "direct_serial"
  port: "/dev/ttyACM0"
  baudrate: 115200
```

文本行协议：

- `RESET` -> `RESET_DONE`
- `START_GRAB` -> `GRAB_DONE` / `GRAB_FAIL`
- `START_RELEASE` -> `RELEASE_DONE` / `RELEASE_FAIL`

## 立即停止

出现这些情况直接停止调试：

- 飞控心跳不稳定。
- MCU 串口无响应。
- HUD 画面明显延迟或 active target 错误。
- 无人机模式、解锁、起飞、降落行为与预期不一致。
- 现场无法保证物理断电或人员安全距离。
