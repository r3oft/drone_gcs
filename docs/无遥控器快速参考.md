```

    --conn /dev/ttyUSB0 \
    --baud 57600 \
    --dry-run
```

**预期**：连接成功，显示飞控状态

### 步骤 2：首次起飞（0.8m，3 秒悬停）

```bash
python scripts/safe_flight_test_no_rc.py \
    --conn /dev/ttyUSB0 \
    --baud 57600 \
    --alt 0.8 \
    --hover 3.0
```

**流程**：
1. 脚本显示安全提示
2. 按 Enter 继续
3. 飞控切换到 GUIDED 模式
4. 电机解锁
5. 无人机上升到 0.8m
6. 悬停 3 秒
7. 自动降落

### 步骤 3：逐步增加难度

```bash

python scripts/safe_flight_test_no_rc.py --alt 1.0 --hover 5.0

# 第三次：1.2m，8 秒
python scripts/safe_flight_test_no_rc.py --alt 1.2 --hover 8.0

# 不要超过 1.5m（安全限制）
```

## 🛑 紧急停止（3 种方式）

### 方式 1：按 Ctrl+C（推荐）

```
正在运行脚本时，按 Ctrl+C
↓
脚本立即执行紧急降落
↓
无人机自动下降
```

**响应时间**：< 1 秒

### 方式 2：断开数传 USB

```
拔掉数传 USB 线
↓
飞控在 5 秒后检测到失联
↓
飞控自动触发 Failsafe（LAND 模式）
↓
无人机自动下降
```

**响应时间**：5 秒

### 方式 3：飞控 Failsafe（自动）

```
如果代码崩溃或无响应
↓
飞控在 5 秒后检测到无心跳
↓
飞控自动切换到 LAND 模式
↓
无人机自动下降
```

**响应时间**：5 秒

## ⚠️ 异常现象与处理

| 现象 | 原因 | 处理方式 |
|------|------|----------|
| 连接失败 | 数传未连接或波特率错误 | 检查 WSL 设备：`ls /dev/ttyUSB*` |
| 无法解锁 | PreArm Check 失败 | 查看 Mission Planner 错误信息 |
| 起飞后晃动 | 传感器未校准 | 按 Ctrl+C，重新校准 |
| 起飞后漂移 | 罗盘干扰 | 按 Ctrl+C，远离磁场干扰 |
| 数传断连 | 距离过远或干扰 | 按 Ctrl+C，检查数传 LED |
| 脚本无响应 | 代码卡死 | 按 Ctrl+C，检查日志 |

## 🔧 常见问题

### Q1：为什么要系留？

**A**：无遥控器意味着无法人工接管。系留装置可以：
- 限制活动范围（防止飞丢）
- 提供物理保护（防止撞击）
- 增加安全冗余

### Q2：Failsafe 真的可靠吗？

**A**：是的，但需要正确配置：
- 必须启用 `FS_GCS_ENABLE = 1`
- 必须设置 `FS_GCS_TIMEOUT = 5`
- 必须设置 `FS_ACTION = 2`（LAND）
- 建议进行测试验证

### Q3：如果 Failsafe 也失败了怎么办？

**A**：这种情况极其罕见，但可以：
1. 按 Ctrl+C 触发代码级紧急降落
2. 断开数传 USB 线
3. 系留绳索会限制活动范围

### Q4：可以飞多高？

**A**：无遥控器模式下：
- **建议**：≤ 1.0m
- **最大**：1.5m（硬限制）
- **原因**：降低风险，便于系留

### Q5：可以飞多久？

**A**：无遥控器模式下：
- **建议**：≤ 5 分钟
- **原因**：电池消耗快，需要频繁充电

## 📞 故障排查流程

### 连接问题

```
1. 检查 WSL 设备
   ls /dev/ttyUSB*
   
2. 检查数传 LED
   应该闪烁（绿色或红色）
   
3. 检查飞控参数
   SERIAL1_PROTOCOL = 2
   SERIAL1_BAUD = 57
   
4. 重新附加设备
   usbipd attach --wsl --busid 3-8
```

### 解锁问题

```
1. 查看 Mission Planner 错误信息
   
2. 常见错误：
   - Compass not calibrated → 重新校准罗盘
   - Accels not calibrated → 重新校准加速度计
   - Need 3D Fix → 切换到 STABILIZE 模式
   
3. 检查飞控 LED
   应该闪烁（绿色 = 正常，红色 = 错误）
```

### 飞行问题

```
1. 起飞后晃动
   → 按 Ctrl+C 紧急降落
   → 重新校准加速度计
   
2. 起飞后漂移
   → 按 Ctrl+C 紧急降落
   → 重新校准罗盘
   
3. 数传断连
   → 按 Ctrl+C 紧急降落
   → 检查数传距离和干扰
```

## 🎓 总结

**无遥控器飞行的核心要点**：

1. **飞控 Failsafe 是最后防线** - 必须完全信任它
2. **代码保护是第二防线** - 多重检查和限制
3. **系留装置是第三防线** - 物理限制活动范围
4. **Ctrl+C 是最后干预** - 随时可以触发紧急降落

**安全原则**：
- 小步快跑，逐步验证
- 每次飞行都要记录
- 任何异常都要调查
- 定期检查飞控参数

**最终建议**：
- 如果可能，购买遥控器
- 无遥控器仅用于代码测试
- 不要在无遥控器模式下进行复杂飞行
